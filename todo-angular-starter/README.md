# To-Do Angular Starter

This repository is a starter Angular project for the To-Do assessment.

## Setup

```bash
npm install
npm start
```

This project uses `angular-in-memory-web-api` as a mock backend.

## Notes

- SLDS (Salesforce Lightning Design System) is included for styling.
- Components:
  - Task list (task-list)
  - Task form modal (task-form)
  - Delete confirm modal (delete-confirm)
- Service:
  - TaskService handles CRUD operations against `api/tasks` provided by the in-memory API.
